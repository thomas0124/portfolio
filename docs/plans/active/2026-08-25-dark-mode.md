## Objective

`prefers-color-scheme: dark` メディアクエリを使い、OS のダークモード設定に自動追従するダークテーマをポートフォリオに追加する。トグルボタンは追加せず、追加ライブラリも不要。

## Scope

- `app/globals.css` に `@media (prefers-color-scheme: dark)` ブロックを追加し、CSS カスタムプロパティを上書き
- `tailwind.config.js` の `darkMode` 設定を確認・修正（必要な場合のみ）
- 全ページ・全コンポーネントで目視確認（ライト/ダーク両方）

## Non-goals

- ユーザーが手動でテーマを切り替えるトグルボタン
- `next-themes` 等のサードパーティライブラリの導入
- カラーパレットの大幅な再設計
- `dark:` プレフィックス付き Tailwind クラスの大量追加（CSS 変数のみで完結させる）

## Assumptions

- Tailwind v3 が使用されており、デフォルトで `darkMode: 'media'` が有効（`@media (prefers-color-scheme: dark)` でトリガー）
- 全コンポーネントが Tailwind のセマンティックカラートークン（`bg-background`、`text-foreground` 等）を使用しており、CSS 変数を差し替えるだけでダーク対応できる
- shadcn/ui の CSS 変数体系（HSL 値）を踏襲する

## Affected areas

| ファイル | 変更内容 |
|---|---|
| `app/globals.css` | `@media (prefers-color-scheme: dark)` ブロックを追加。`:root` の全 CSS 変数に対応するダーク値を定義 |
| `tailwind.config.js` | `darkMode: 'media'` が明示されていない場合は追記（Tailwind v3 デフォルトと同値だが明示的にする） |
| `components/layout/Header.tsx` | `bg-background/85` や `bg-transparent` など背景色に関わるクラスを目視確認。必要なら `dark:` クラスを追加 |

## Design decisions

**Critical forks: None**

- トグル方式: 「OS 設定のみ追従（`prefers-color-scheme`）」を選択。理由: シンプルさ最優先・追加ライブラリ不要・ユーザー指定済み。
- 変数上書き方式: CSS カスタムプロパティを `@media (prefers-color-scheme: dark)` 内で再定義する方式を採用。コンポーネントを一切変更せずに済む。個別コンポーネントへの `dark:` クラス付与は、変数で賄えないケースのみ許容。

## Implementation outline

1. `tailwind.config.js` に `darkMode: 'media'` を追記（なければ）
2. ダーク用カラーパレットを設計（既存ライトカラーの補色・明度反転を基準に）
3. `app/globals.css` の `@layer base` に `@media (prefers-color-scheme: dark) { :root { ... } }` を追加
4. dev server を起動し、Chrome の DevTools で強制ダークモード切り替えて全ページ目視確認
5. Header の `bg-background/85` やモバイルメニュー背景など、透明度込みのクラスを確認・必要なら調整
6. `bun run build` + `bun run lint` でエラーなしを確認

## Risks and mitigations

| リスク | 影響 | 対処 |
|---|---|---|
| `bg-background/85`（透明度付き）でダーク背景が意図通りにならない | Header の視認性低下 | 実装後に目視確認。必要なら `dark:bg-[HSL値]/85` を追加 |
| shadcn/ui の将来バージョンとの変数名衝突 | CSS 変数が上書きされる | 変数名を `:root` スコープで管理し、shadcn 標準に準拠することで最小化 |
| `prefers-color-scheme` に未対応のブラウザ | ダークモードが適用されない | 非対応ブラウザではライトモードにフォールバック（仕様通り）。対処不要 |
